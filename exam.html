📚 Subjects to generate

Tip: Search, filter by teacher/class, then tick. Only ticked subjects will be autogenerated.

1. Subject groups

Subjects that must be scheduled together for selected classes.

2. Same period (class arms)

Selected arms get the same subject / group at the same day & period.

3. Double period (2 periods/week)

Tick subjects with 2 periods/week that must be one consecutive double.

Tick subjects that must never get a double period.

4. Teacher unavailable

Teacher cannot teach on selected days and/or periods.

Rules are saved with the timetable. Generate still respects JUMAT, clashes, and quotas.

📅 Different Times Per Day

Set different start/end times for each day. Example: Period 1 on Monday 08:00-08:40, Tuesday 08:15-09:00, Friday 07:45-08:30. Leave blank to use the default period time.

For print: when per-day times enabled, each cell shows its own day-specific time, and header shows only Period labels.
